# Brands: seed material

In the app, each brand lives in the database and is set up through onboarding. These folders are the inputs for Katy's own brands, so their onboarding can import what already exists instead of starting from scratch. They're not code and nothing here is loaded by the app directly.

| Folder | What's in it | Used in |
|---|---|---|
| `boutiqly/` | Brand rules and voice, strategy and posting times, colors, and notes on its current prototype studio (120+ pieces, 163 tagged assets) | M5, onboarding Boutiqly as the second brand |
| `make-space/` | To fill: Make Space's brand docs, plus where its prototype data lives | M2 (Make Space moves in), M3–M4 (its style set and Reel styles) |

Rule for all of it: a brand's material is only ever used for that brand's posts.
